# SOLR-17887: Implement File Tree Component (new UI)

Draft PR description. Not opened as a GitHub PR.

## What

Adds `FileTree`, a reusable Compose composable in `ui/shared` that shows files and folders in an IDE-style list.

- Folders show a chevron that is collapsed (right) or expanded (down). A single click on the chevron toggles the folder.
- Double-clicking a folder name also toggles it.
- Files and folders show their names as written. A file's extension is part of its name.
- A single click on any item calls `onItemClick`. A double click calls `onItemDoubleClick`. Selection is highlighted from the `selectedPath` input, so the caller owns the selected state.
- Expanded state lives inside the component.

The data model is `FileTreeNode`, with `FileTreeFile` and `FileTreeFolder` children, and it does not depend on any API.

Out of scope, per the ticket: right-click menus, search, and the file viewer (SOLR-17911, separate branch).

## Behavior note

A single click reports after the double-click window (about the platform's double-click timeout), because `combinedClickable` must wait to tell a single click from a double click. Selection therefore lags a single click by that window.
