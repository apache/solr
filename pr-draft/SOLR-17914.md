# SOLR-17914: Implement Create Collection Dialog (new UI)

Draft PR description. Not opened as a GitHub PR.

## What

Adds `CreateCollectionForm`, a composable in `ui/shared` for creating a collection from an existing configset. It has a name field, a configset picker (the existing `ConfigsetsDropdown`, with the first configset selected by default), shards and replication-factor fields, an inline error under the name, a general error line, and Create and Cancel buttons.

The form keeps the typed values itself. The caller supplies the configsets, the two error messages, and the actions. Create is enabled only when the name is not blank and the shard and replica counts are positive whole numbers.

The create call itself (`POST /api/collections`, `CreateCollectionRequestBody`) and the Collections screen that hosts the dialog are not in this change. The advanced options and tooltips are a child ticket.
