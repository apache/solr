# SOLR-17913: Implement Collections Details Card (new UI)

Draft PR description. Not opened as a GitHub PR.

## What

Adds the Collection Details card, a display-only composable in `ui/shared`, and the `CollectionDetails` domain model it shows.

- The card lists the collection name, config set, shard count, replication factor, router, max shards per node, and whether auto-add replicas is on.
- The card is wrapped in the shared `SolrCard` and its values can be selected for copy.
- No interactions. The composable takes a `CollectionDetails` directly, as the ticket allows.

## Open point

The Figma field list is not reachable from the pool host. The fields above are the ones the Collections API reports for a collection. Confirm the list against the design before merge, and add or remove rows in `CollectionDetailsCard.kt` if the design differs.

## Not in this change

The Collections screen, its navigation (Collections is still disabled in the sidebar), and any data loading. The card has no caller yet.
