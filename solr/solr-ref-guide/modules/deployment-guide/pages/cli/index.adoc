The `bin/solr` command line tool is built on https://picocli.info/[picocli].
This page and the per-command pages linked below are the references for its commands and options.
Run `bin/solr <command> --help` for the same information on the command line.

== Falling back to the legacy CLI

The previous Apache Commons CLI implementation still ships with Solr.
Use it only as an escape hatch if you run into a problem with the default CLI, and please report the problem to the Solr project.
Its options and output differ in places; see xref:solr-control-script-reference.adoc[] for its documentation.

To switch, set `SOLR_PICOCLI` in your `solr.in.sh` (or `solr.in.cmd` on Windows):

[source,bash]
----
SOLR_PICOCLI=false
----

Or set the equivalent system property for a single invocation:

[source,bash]
----
SOLR_TOOL_OPTS="-Dsolr.picocli=false" bin/solr status
----
