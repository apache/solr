// tag::picocli-generated-man-section-options[]
== Options

*--cert*=_FILE_::
  *(required)* PEM certificate chain, with the server certificate first.

*-h*, *--help*::
  Print this help message and exit.

*--key*=_FILE_::
  *(required)* PEM private key. Requires OpenSSL on PATH.

*--key-password-file*=_FILE_::
  Password file for an encrypted PEM private key.

*--keystore*=_FILE_::
  Destination keystore. Default directory: server/etc in the Solr installation.

*--password-file*=_FILE_::
  *(required)* File containing the keystore password on one line.

*--solr-include-file*=_FILE_::
  Existing solr.in.sh to update. Defaults to bin/solr.in.sh in the Solr installation.

*--store-type*=_TYPE_::
  Keystore format: JKS or PKCS12. Default: JKS.

*-v*, *--verbose*::
  Enable verbose mode.

*--zk-host*=_HOST_::
  ZooKeeper connection string. If supplied, set urlScheme=https for the entire cluster.
